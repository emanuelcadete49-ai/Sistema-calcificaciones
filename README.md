 ## 📋 Descripción del programa
 El programa realizado en C++ permite registrar la cantidad de estudiantes, solicitar tres notas por cada alumno, calcular el promedio individual, indicar si el estudiante está aprobado o reprobado, y al finalizar muestra el promedio general de todo el grupo. Solo utiliza variables y bucles, respetando las restricciones de la tarea.
 ## 📥 Datos de entrada
 1. Cantidad total de estudiantes (debe ser mayor a 0)
 2. Nombre de cada estudiante
 3. Tres calificaciones por cada estudiante
 ## ⚙️ Proceso
 1. Se recibe la cantidad de estudiantes
 2. Se ejecuta un bucle para recorrer alumno por alumno
 3. Se capturan las tres notas, se suma y se calcula el promedio de cada uno
 4. Se compara el promedio para saber si aprobó o reprobó
 5. Se acumula la suma de todos los promedios para obtener el promedio general del grupo
 ## 📤 Salida
 ‑ Nombre de cada estudiante
 ‑ Promedio individual
 ‑ Estado: Aprobado / Reprobado
 ‑ Promedio general de todo el grupo
 ## 🔁 Explicación de los bucles utilizados
 ✅ **Bucle do‑while**: Lo usé para validar la cantidad de estudiantes, para obligar a que el usuario digite un número mayor a cero, repite la petición hasta que el dato sea correcto.
 ✅ **Bucle for**: Lo usé para recorrer cada uno de los estudiantes, se repite la cantidad de veces que indicó el usuario, para pedir las notas a cada alumno.
